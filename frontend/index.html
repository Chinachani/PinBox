添加到手机桌面（免安装直达）
局域网环境下，直接创建快捷方式即可获得与独立 App 完全相同的全屏体验：
📱 安卓手机 (Edge / Chrome / 系统自带浏览器)：
1. 点击浏览器底部或右上角菜单按钮（三个点 ... 或 ☰）；
2. 选择 【添加到主屏幕】 或 【创建快捷方式】；
3. 手机桌面即可生成专属的 PinBox 芯片图标，点击一键直达！
🍎 苹果手机 (iPhone / Safari)： 点击底部中间的分享图标 ➔ 滑动选择 【添加到主屏幕】 即可。
数据中心 · 离线与同步
手机装到桌面后可完全离线使用（数据存本机）；回到局域网后把离线变更推送到服务器，或拉取服务器最新库存覆盖本机。
